# Домашнее задание 1: кластеризация

Ноутбук с заданием: [`01_clustering.ipynb`](01_clustering.ipynb).

В работе нужно сравнить K-Means, агломеративную кластеризацию и DBSCAN на данных о клиентах магазина.

Для запуска скачайте `Mall_Customers.csv` из [Mall Customer Segmentation Data](https://www.kaggle.com/datasets/vjchoudhary7/customer-segmentation-tutorial-in-python) и положите файл в эту папку.

В сдаваемом ноутбуке должны быть выполненный код, все графики и краткие выводы к заданиям.
